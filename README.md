
# API de Livros - Flask

Projeto desenvolvido para a AV2 da disciplina Web Coding.

## Objetivo
Criar uma API para apresentar informações de três livros em formato JSON.

## Tecnologias utilizadas
- Python
- Flask

## Instalação
pip install -r requirements.txt

## Como executar
python app.py

## Rota da API
GET /livros

http://127.0.0.1:5000/livros

## Livros cadastrados
- Dom Casmurro
- O Cortiço
- A Hora da Estrela
