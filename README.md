
# Projeto API de Livros

Projeto desenvolvido para a disciplina de Programação - Web Coding.

## Parte 1 - Back-end

API desenvolvida com Python e Flask.

### Funcionalidade
- Consulta de três livros.
- Retorno dos dados em formato JSON.

### Rota
GET /livros

### Executar
python app.py

## Parte 2 - Front-end

Interface desenvolvida com React e Vite.

### Funcionalidades
- Exibição do catálogo de livros.
- Botão Buscar Livros.
- Consulta à API Flask.
- Exibição dos livros recebidos.
- Mensagens de carregamento e erro.

### Executar

Entre na pasta do frontend:

cd frontend-livros

Instale as dependências:

npm install

Inicie a aplicação:

npm run dev

## Tecnologias utilizadas
- Python
- Flask
- JavaScript
- React
- Vite
